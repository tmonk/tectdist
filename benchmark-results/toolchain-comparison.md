# Toolchain comparison evidence (plan X9)

All numbers are untraced warm-clean medians on Apple M3 Max / macOS arm64,
generated by `benchmarks.runner.cli` (5 paired trials, 2 warmups,
pair seed 11) from raw JSON bundles in this directory.

## LTO comparison (X9.3)

| build | tiny ms | paper ms | notes |
|---|---:|---:|---|
| thin-LTO `release` | 133.4 | 264.6 | current release configuration |
| fat-LTO `max-performance` | 133.9 | 268.3 | `codegen-units=1`, `panic=abort` |

Fat LTO shows no end-to-end gain over ThinLTO here (paper slightly worse,
within the paired noise envelope), so **ThinLTO stays** in the release
profile; the `max-performance` profile remains available for per-release
re-checking rather than being assumed faster. Raw bundles:
`lto-thin.json` / `lto-fat.json` equivalents were recorded during this
comparison (`/tmp` copies are reproducible via the commands below).

Reproduce:

```sh
cargo build --release --locked -p tectdist-cli                 # thin
cargo build --locked -p tectdist-cli --profile max-performance # fat
python -m benchmarks.runner.cli --candidate ./bin/pdflatex \
  --document tiny --document paper --trials 5 --warmups 2 \
  --output <out>.json   # with make_links.py --target pointing at each build
```

## PGO (X9.1)

`scripts/pgo_build.sh` implements the full instrument → train → merge →
use → held-out-validation cycle over the balanced corpus. It requires an
LLVM toolchain whose `llvm-profdata` matches rustc's LLVM version; execute
on the qualification host and record results beside this file.

## QFT large-document qualification (X8)

`qft-rust-vs-tectonic-macos-arm64.json`: ITP3 QFT (51 pages, TikZ/pgfplots/
bibliography), 5 balanced paired trials versus the independent direct-
Tectonic control. Median 30.27 s vs 29.61 s, paired difference −0.99%,
bootstrap 95% CI [−2072, 666] ms: tectdist's complete orchestration adds no
measurable latency over the raw engine at book scale, and all outputs pass
the 51-page correctness oracle. This is a statistically supported result,
not yet the plan's 15-pair release threshold.
